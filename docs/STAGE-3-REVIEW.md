# 阶段3 · 角色与探索交互 · v0.3.0

## 本次范围

用户明确要求舍弃区域探索并进入阶段3。已移除五区视图、分区图层和路口切换，改为一张连续校园地图。旧阶段2实现保留在 `stage-2-v0.2.0` 标签中。

交付：男女大学生四方向基础行走、WASD/方向键控制、镜头跟随、建筑及水面碰撞、靠近地标/NPC的E/空格交互、暂停与恢复、M键全景定位、原位置返回。建筑外侧交互目前显示已确认的地标图片；没有制作建筑内部、正式剧情或关卡。

## 美术

- 使用内置imagegen依据用户提供的男女大学生设定，分别生成两张1024×1536透明PNG，四行方向依次为下、左、右、上，四列为行走帧。
- 每个源单元格256×384。逐单元格测量alpha>=128内容边界，检查16格均有角色、未碰到格边、头脚未被截断；绘制采用统一比例及脚底对齐。
- 完全透明像素比例：男生约66.1%、女生约60.2%。无需假装透明底或拼贴设定板直接入场。
- 图像已目视核对方向、蓝白外套、背包、男女发型和四帧变化；基础行走连续性与小尺寸清晰度还需浏览器试玩验收，不声称达到最终美术质量。
- 素材：`public/assets/sprites-v0.3.0/`；完整提示词：`STAGE-3-SPRITE-PROMPTS.json`。角色选择立绘、地图与六处地标图片未覆盖。

## 碰撞与交互

- 世界3344×1882，依据当前斜俯视全景的36组建筑轮廓、3组水面和校园边界阻挡。
- 轮廓为图像近似，不是测绘模型；没有将不明建筑命名或定稿真实入口。
- 小步轴向碰撞、墙边滑动、斜向速度归一化、长时间帧间隔限制。
- 六处地标及筑小智均设置在可通行地面的交互位置；靠近后显示提示。展示图片或阶段说明时暂停，切换画面保存当前位置。
- 失焦、页面隐藏、松键和屏幕方向按钮取消时清空输入，降低误走风险。

## 实际验证

- TypeScript与Vite生产构建检查通过；`git diff --check`通过。
- 运行`node scripts/check-stage3.mjs`：四方向、斜向速度、建筑/水面/外界阻挡、长时间朝墙移动防穿透、镜头边界、精灵帧结构通过。
- 在离散可行走地面中寻找路线后，使用游戏同一`movePlayer`函数以60步/秒实际模拟走向7个交互点，过程中逐步检查未进入阻挡区域、最终最近交互对象正确。六个地标与NPC全部可达，不是只检查图上连线。
- 使用同一`renderGame`函数进行原生Canvas绘制，男女角色实际渲染预览已生成并目视检查。`artifacts/stage3-render-boy.png`、`stage3-render-girl.png`为渲染输出，**不是浏览器截图**。

## 试玩验收

1. 从首页选角色并进入校园；试WASD、方向键、斜向移动和松键停止。
2. 走近西门内的筑小智，E交谈，Esc或示例结束后返回；观察位置是否保持。
3. 沿路走到图书馆和其他光点，E查看地标图片；西门和学院保留双图切换。
4. 贴近建筑、水边，检查是否有明显穿越或被过大轮廓挡路的地方；可截图标注以便只修对应轮廓。
5. M查看全景和当前位置，再返回探索；相机不应重置到出生点。
6. 男女角色都试一次，观察方向、步伐和视觉比例；如果碰到路径问题，可点“回到西门”。
