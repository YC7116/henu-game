# 606 南大门搭建展示台 · v0.8.3

606 新增有实体碰撞的微缩模型展示台，靠近按 E 或点击提示打开搭建界面。使用用户指定的 Blender 文件后台导出 GLB，原始 .blend 未被覆盖。模型拆为四组：基座庭院、门柱墙体、木门匾额、飞檐屋瓦，约九秒依次浮落归位。展示台高度与模型缩尺已适配606室内净高；搭建面板会切换到近距离俯视，退出后恢复步行视角。

完成后可重播或点击「打开3D环绕详细展示」，在游戏内打开本地 /gate-viewer/index.html 。详细展示资源已从用户提供的 5277 服务复制进项目，不再依赖该独立服务。当前导出的游戏 GLB 在 public/assets/models/henu-south-gate-assembly.glb；导出过程在 scripts/export-gate-display.py。

状态使用 localStorage 的 henu-south-gate-built 保存。当前为可直接体验的搭建演示，不检查四块碎片是否已齐，也不会额外发放碎片。将来可再接入统一收集进度。加载时禁用搭建，失败可重试；关闭教室释放模型资源；退出面板可继续原有606大屏小游戏。
