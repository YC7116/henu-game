# 内嵌详细展示与恢复楼下起点 · v0.8.4

建工院从楼下入口引道开始。App不再通过tour=inside606等参数自动打开三维场景或选择606机位。点击地标入口后固定采用entry初始机位，回到入口同样返回楼下。先前给出的直达606审核链接已停用。

建成南大门后，点击「查看3D环绕详细展示」在游戏主容器内打开iframe，支持方向预设、拖动、缩放和自动旋转。关闭或按Esc回到搭建展示台，保留搭建完成状态。没有target=_blank或window.open。内嵌期间暂停背后的三维渲染循环，避免两套模型同时持续绘制。

public/gate-viewer 的模型、查看器、参考图和本地Three.js依赖来自用户提供的 http://127.0.0.1:5277/ 页面，保持同一份详细模型及光照设置，仅调整页面为内嵌布局并添加Esc关闭消息。游戏无需另外启动5277服务。详细模型与606上的搭建模型是两份导出资产，后续修改原始.blend时需要分别更新。

验证：类型检查、生产构建通过。浏览器实测旧直达URL不再直接进入606；正常建工院入口显示「入口引道」。专用测试页挂载同一606组件，确认内嵌iframe模型可见、侧面按钮可用、自动旋转aria-pressed=true、关闭后搭建面板仍在。截图见artifacts/gate-embedded.png。测试页在artifacts下，不随源码包交付。
