- 删除水系“等你找齐，我们再看看你的猜想对不对。”，正常路线下接“终于集齐四块碎片了，接下来去建工学院606揭晓答案吧”。
- 提前进入水系时检查图书馆、教学楼、体育场完成记录；如未集齐，准确提示尚未完成的地点，不误报四块。
- 西门、水系前后、教学楼筑小智、老师、图书馆、赛跑前后、606搭建前后与收尾对话均支持上一句按钮、左方向键回看、右方向键向前。

- 普通结束页和碎片展示页按空格退出；西门/水系前导的结束页空格返回校园，不自动进入小游戏。
- 赛跑/搭建前末句空格关闭对话留在当前场景，开始活动仍需选择按钮；赛后末句空格接收碎片进入展示，随后空格返回校园；606结尾末句空格进入收尾画面，随后空格返回校园。
- 对话期间左右键不移动角色；按钮已获焦点时，空格仍按对话快捷键处理；长按重复事件忽略。
