# 阶段2 · 校园地图与区域结构 · v0.2.0

用户已明确同意进入阶段2。阶段1基线为 `stage-1-v0.1.2`。本阶段完成后暂停，等待验收；不自动进入阶段3。

## 查看流程

1. 开启寻迹 → 选择角色 → 先看全景 → 从西门启程。
2. 在西门·图书馆区域打开地标；图书馆仍显示用户提供的新版图片。
3. 点击图中路口按钮，或底部相邻区域卡片，切换到相邻区域。
4. 按M查看全景，再按M或“返回区域”回到原区域。角色和区域选择不重置。
5. 在全景切换“区域/地标”图层，选择不同区域进入，或查看六处地标。
6. 图书馆可进入原有示例对话，示例结束后返回校园；未新增正式剧情。

## 地图真实性及未定稿事项

- 保留用户确认的西大门在图书馆正前方的关系；学院重点位置仍在地图画面中图书馆左下侧，水系连接中央楼群，志义体育场在画面右侧。此处“画面方向”不是实际罗盘方向。
- 全景底图及地标编号沿用已确认版本，没有因分区而移动关键建筑或重画学院。
- 区域地图暂以同一像素全景放大裁切，因此道路、水系和绿地保持视觉连续；尚未制作可行走瓦片地图、建筑/水面碰撞或动作精灵。
- 六条连接是根据原图及现有全景空间关系提出的衔接草案；连线只是连接示意，不是精确导航路线。“馆前步道”等为原型描述，不宣称为真实道路名称。
- 当前出口位置、路径可达性与区域尺度仍需熟悉校园的用户确认。没有自动给不明建筑命名、认定真实建筑入口或将所有道路定稿。
- 区域切换通过按钮触发并淡入；“角色走到出口自动切换”留在阶段3。阶段2不包含自由移动、任务内部、解谜、存档、正式剧情或正式任务。
