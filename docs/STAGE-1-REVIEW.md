# 阶段 1 验收单

项目：《河大寻迹：金明秘境》  
版本：阶段 1 / 视觉原型初稿  
状态：待用户试玩和视觉验收。**未经明确确认，不进入阶段 2。**

## 预览时建议查看的流程

1. 打开首页，观察像素校园背景、游戏标题、配色和按钮尺寸。
2. 进入主角选择，分别查看男生与女生的形象、背包、蓝色外套、发型和整体比例。
3. 查看金明校区全景，重点比较西大门、图书馆、建筑工程学院、水系、中心教学区和志义体育场的相对位置。
4. 查看图书馆与建筑工程学院的近景像素草稿，判断辨识度和建筑材料表现。
5. 进入筑小智示例对话，检查屋顶帽、服装、1931、学院徽记、图纸筒和蓝色模型，以及立绘和文字框的比例。
6. 返回首页或地图，确认界面切换自然、文字清楚、按钮可用。

具体可用按钮、快捷键、预览链接与截图以本版本 README 和实际界面为准。

## 本阶段需要进一步确认的问题

1. 当前像素颗粒、环境细节与暖色调是否达到期望？需要更清晰的游戏像素感，还是更柔和的插画感？
2. 男、女主角的脸型、发型、服装和身材比例是否满意？
3. 筑小智是否足够忠于原始海报？尤其请检查屋顶形状、胸徽和 1931 在当前尺寸下的清晰度。
4. 黑圈内哪几个具体楼体属于需要重点保留的建筑工程学院？希望表现的正面和入口位于哪一侧？本阶段不替用户认定。
5. 图书馆及学院像素草稿的外形是否对应实际印象？若需更准确的立面，可在后续修改时补充实景依据。
6. 原始海报的“土木建筑学院”与任务书的“建筑工程学院”如何在游戏中统一？使用哪一版名称与院徽？
7. 首页、角色选择与对话框的尺寸、文字大小和画面比例是否舒服？

这些问题用于当前阶段验收，不代表要求用户现在定稿故事、关卡或后续地图结构。

## 草稿与尚未开发内容

- 校园全景、建筑与人物新增美术为 AI 辅助阶段 1 草稿，需用户确认后再用于后续阶段。
- 建筑像素图依据示意地图提炼，未经过真实立面测绘；不明建筑名称、具体入口和圈内归属尚未确认。
- 角色当前为静态视觉，尚未制作和验证四方向动作精灵表。
- 示例对话仅验证形象、语气与界面，不是正式开场剧情或已经确认的世界观。
- 不包含自由移动、镜头跟随、碰撞、完整区域切换、建筑内部、正式任务、小游戏、存档、结局或通关流程。
- 音乐音效、完整动画、正式比赛部署和兼容性完善属于后续阶段范围。
