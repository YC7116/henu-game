# 水系黑天鹅活动接入

- 水系地标 04 默认展示用户提供的「像素艺术黑天鹅湖畔公园.png」，并通过图片切换保留原来的水岸与步道局部图。
- 在校园全景点击 04，或沿路走近水系按 E，打开展示后选择「举起手机，拍摄黑天鹅」。
- 使用本地随站点发布的三维小游戏，不跳转到另一个站点，不依赖独立试玩站的登录状态。
- 五轮速度为 110、145、185、235、290；空格或快门拍摄。结束可重玩或返回水系，也可随时点击顶部返回按钮或按 Esc。
- 返回原来的全景或探索界面，并重新显示水系图片；探索角色位置保存在原有 playerStore 中。
- 未新增奖励规则、碎片、剧情；教学楼、体育场功能未变。

接入组件：`src/SwanMission.tsx`；素材和小游戏：`public/games/swan/`。Three.js 0.160.1 与 MIT 许可一同保留。独立试玩项目仍保留，接入版额外包含返回水系消息与内嵌布局，未来调整玩法时应同步两份版本。

验证：TypeScript 检查、Vite 生产构建、原有路线检查、`node scripts/check-swan.mjs` 均通过；新增图片及全部游戏模块本地 HTTP 返回 200。抓拍测试覆盖五轮、重复快门保护、重玩、隐藏标签页暂停、错过天鹅、结果返回按钮和 Esc 返回请求。浏览器连接超时，真实布局、WebGL 效果及完整鼠标/键盘进入返回流程仍待试玩验收。
