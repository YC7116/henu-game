## 校园地图的可见空间关系

以下均描述**参考图的画面位置**，不是对真实地理方位的推断。原图北箭头指向画面左下，故不能按常见“上北下南”读图。

- **西大门**：原图上斜边中段明确标有“金明校区西门”，与校内宽阔道路、广场及图书馆形成可辨认的空间联系；其确切可交互入口与近景立面暂未确认。
- **图书馆**：画面中心偏上，灰白色现代建筑，蓝色窗格，体量高低错落；近侧可见弧形体量和低翼，附近有广场、旗杆与水面。
- **建筑工程学院**：位于图书馆画面左下方向，贴近水系。用户圈出的范围内可见红砖/红色立面、灰白屋顶、蓝色窗格的长条多层体量。“建筑工程学院”标牌提供位置依据。
- **学院周边的歧义**：黑圈右侧邻近“物理与电子学院C楼”，下方邻近“地理科学与工程学部”等标签。黑圈涉及的体量不能全部据此定名为学院建筑；本阶段不推断楼号和入口。
- **中心教学区**：图书馆画面右下方向，一组浅色长条教学楼围绕圆形/弧线广场布置，旁边连接水系。
- **水系及广场**：有图书馆近侧水面、穿过中心教学区周边的曲折水道、桥梁及岛状绿地，是全景辨识的重要骨架。
- **志义体育场**：画面右下，橙色环形跑道、绿色运动场及彩色看台；不能与画面更下方另一处标为“运动场”的场地合并或混淆。

本阶段全景是构图和美术方向初稿。允许在视觉稿中压缩距离，但道路通行关系、区域边界、可走范围、碰撞和区域连接均尚未建立，不作为阶段 2 地图结构的验收成果。

任务书采用“建筑工程学院”；筑小智原始海报和像素设定板可见“土木建筑学院”字样。本阶段界面沿用任务书中的项目称呼，角色学院徽记参考用户提供的海报；不据此断言学院的现行正式名称，也不擅自重绘一套新院徽。后续需用户确认游戏中最终采用的学院名称、徽章版本及小尺寸呈现方式。

## 新增素材的真实性与使用状态

- 本阶段新增的校园、建筑与人物图均为 **AI 辅助生成的阶段 1 像素视觉草稿**，用于评估画风和界面比例，尚非用户验收后的正式素材。
- 建筑草稿从校园示意图提炼轮廓和材料，未经过实景照片或测绘资料验证。若外形与实际不符，应在当前阶段依据用户反馈修改。
- 人物草稿为静态立绘。即使背景透明，也不能直接宣称是 32×48 的正式动画帧或可用的四方向精灵表。
- 筑小智的屋顶帽、1931、学院胸徽、图纸筒、蓝色建筑模型必须逐项核对；生成图中的微小文字和标志可能存在偏差，需在验收时明确。
- 风格参考截图仅作为观察依据，原图素材不进入最终游戏资源。
