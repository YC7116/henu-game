# v0.8.2 合并与全屏修正（2026-11-07）

以「河大寻迹-整合版-水系对话」为底，加入 v0.8.1 操场版本的 src/tour、Three.js 本地模块、geo、奖励图和奶蛙 GLB；保留教学楼室内关卡、图书馆问答、水系双图与完整奖励对话。原有路线和行走素材继续采用整合版，避免覆盖两方已有内容。

入口：全景或步行路线 → 05 志义体育场 → 进入体育场；06 建筑工程学院 → 进入建工院探索。

修正：两个三维活动挂在同一个持久 main 游戏容器内；它们现在是 requestFullscreen 目标的后代。活动内提供全屏/退出全屏按钮，ResizeObserver 与 fullscreenchange 更新渲染尺寸。开启活动时校园移动和全局快捷键暂停。失焦清理按键；退出活动释放画布和鼠标锁定。操场画布可获取键盘焦点；鼠标锁定失败时保留键盘控制。

验证：类型检查、生产构建、原路线模拟、水系五轮抓拍与对话奖励回归通过。真实浏览器中验证了先全屏再打开操场菜单，启动决赛流程，及全屏状态下 C 键切换视角；建工院全屏进入参观，P 键切换画质，画布可见，已保存截图。检测依据包含 main[data-fullscreen=true]（由浏览器 fullscreenchange 更新）。未宣称完整跑完每种角色比赛、遍历建工院全部楼层或跨浏览器兼容性已全部测试。

本地启动：安装依赖后 npm run dev -- --host 127.0.0.1；当前预览 http://127.0.0.1:5177/ 。本机 node_modules 链接复用已安装的相同版本依赖；源码包不含该链接、Git 历史及构建产物，需要自行安装依赖。
