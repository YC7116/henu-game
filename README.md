# 河大寻迹：金明秘境

当前：阶段3 · 角色与探索交互 · v0.3.1。

用户已明确要求舍弃分区探索，因此现为一张连续校园地图：角色真正移动，镜头随行，靠近地标/NPC再互动。本轮按用户新画的路线开放连续道路走廊；其他道路尚未开放。阶段2界面、分区与路口按钮已移除，旧实现可通过阶段标签回看。

## 试玩

- 开启寻迹 → 选择男/女大学生 → 开场全景 → 进入校园路线试玩。
- 点击“从西门演示全程”：实际行走约32秒，经图书馆、综合教学楼、体育场、校园水系，到达建工学院；方向键立即接管，显示地标图片时演示暂停。
- “隐藏路线”关闭地面引导虚线；“回到西门”重置位置和本轮到达标记。
- 地标编号仍为01西门、02图书馆、03综合教学楼、04水系、05体育场、06建工学院；本轮访问顺序为01→02→03→05→04→06。
- WASD或方向键：移动；斜向速度经过归一化。
- E或空格：与附近金色光点所代表的地标或筑小智交互；亦可点击提示按钮。
- M：打开校园全景，再次按M或“返回原位置继续探索”返回原位置。
- Esc：关闭地标；在对话中返回校园；探索中查看全景。
- 回到西门：返回出生点，方便测试。
- 窄屏提供方向按钮作为辅助，优先电脑键盘体验。

六处地标编号和图片保持用户确认版本：01西大门（校名、校训双图）、02图书馆、03综合教学楼、04校园水系、05志义体育场、06建筑工程学院（入口、楼体双图）。原有示例对话使用同版图书馆背景，未新增正式剧情。

## 本次实现

- 两张1024×1536透明行走精灵表，每张4方向×4帧；256×384源单元格。
- 依照透明内容边界取帧，脚底居中对齐；走动按实际位移播放，停止时使用站立帧。
- Canvas连续世界、跟随镜头、小地图实时位置、页面切换位置保留。
- 沿可见铺装手工描绘的57个道路转折点，形成连续可行走走廊；分小步检测路缘阻挡。旧版宽泛楼体轮廓曾阻断真实道路，本轮改用路线走廊限定脚下通行范围。
- 6处建筑/地标外侧交互点及筑小智场景交互；显示图片时暂停移动。
- 切换窗口、失焦、松键及方向按钮取消时清除输入，避免持续误走。

## 素材与限制

场景沿用已有像素全景，并保留西门局部修正；未重画地图或用户提供的地标图片。两名主角的新行走图使用内置imagegen根据用户角色设定生成，完整提示词见 `docs/STAGE-3-SPRITE-PROMPTS.json`。原始透明PNG保存在 `public/assets/sprites-v0.3.1/`，没有覆盖角色选择立绘。

本轮是指定路线的审核版本，只能沿所描绘的道路走廊行走，暂不开放全部校园道路。路线依据用户IMG_1090.heic红线顺序，贴合当前像素全景中的铺装、桥面与水岸步道；不会用原始宽泛楼体轮廓阻断这些路径。它不是实地测绘，楼体遮挡和局部贴边手感仍需要试玩校对。未加入自由进入建筑内部、正式任务、正式剧情、关卡、存档或结局。本次按用户要求取消分区，因此没有区域切换；所有步行发生在同一校园世界中。

## 验证

`pnpm run build`：类型检查与生产构建。
`pnpm check:stage3`：移动、斜向速度、路缘阻挡、完整路线在30/60/144帧下的逐步行走、到站顺序、无瞬移、反向手动步行、7个交互点、镜头边界和精灵帧结构。

本次还用相同的游戏渲染函数在原生Canvas中生成了 `artifacts/stage3-render-boy.png` 和 `stage3-render-girl.png`，以及六站渲染拼图 `artifacts/stage3-route-stops.png` 和路线总览 `artifacts/stage3-route-overview.png`。这是游戏渲染预览，不是浏览器截图。浏览器连接超时，因此键盘事件、真实帧率、图片弹窗暂停与M键返回流程未完成端到端复测；模拟通过不等同于已经试玩通过。

## 本地运行

要求Node.js 22+、pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm check:stage3
pnpm preview
```

本机默认预览 `http://127.0.0.1:5173/`，以服务打印地址为准。线上使用原私有预览站点，实际发布结果见聊天交付。

## 代码

- `src/ExploreGame.tsx`：输入、画布循环、暂停、图片加载、交互提示、小地图。
- `src/world.ts`：路线走廊阻挡、物理移动、逐点演示、到站判定、交互与镜头计算。
- `src/walking-route.ts`：当前审核路线57个转折点和六个停留点。
- `src/RouteGuide.tsx`：全景与小地图共用的路线指示。
- `src/game-renderer.ts`：校园与角色绘制；测试与游戏共用。
- `src/sprite-frames.json`：实测源帧范围、方向顺序与统一绘制比例。
- `src/CampusMap.tsx`：连续地图全景和当前位置。
- `src/App.tsx`：首页、角色选择、全景/探索/展示/示例对话流程。
- `src/content.ts`：既有地标照片与短对话；没有正式剧情定稿。
